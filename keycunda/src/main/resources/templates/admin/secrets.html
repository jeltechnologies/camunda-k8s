Secrets

Letters, digits or "_", not starting with a digit. Must be unique.

Multi-line values (e.g. a service-account JSON key) are supported.

Accepts a Kubernetes kind: Secret manifest (.yaml/.yml, reading both data and stringData) or a .env file (KEY=VALUE lines; a multi-line value like a JSON key doesn't need to be quoted). Keys already present here are updated; nothing is removed.
